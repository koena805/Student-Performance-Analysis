# Student Performance Management System

## 1. Problem Statement

Managing student academic performance manually can be time-consuming and may lead to errors while recording, calculating, and reviewing student marks and attendance. Teachers and institutions need a simple system to store student information, process academic data, calculate performance, and present the results in a clear format.

The Student Performance Management System is designed to provide a structured way to manage student records, marks, attendance, and performance information.

## 2. Scope of the Project

The scope of this project includes:

- Storing student details such as Student ID and Student Name.
- Managing attendance information.
- Recording marks for different subjects.
- Processing student academic data.
- Calculating performance-related results.
- Displaying student performance information in a clear and organized manner.
- Using a CSV file to store student data.
- Providing a simple and understandable system for managing student performance.

## 3. Target Users

The main target users of this project are:

- Teachers
- Faculty members
- School or college administrators
- Students who need to review their academic performance

## 4. High-Level Features

The major features of the Student Performance Management System are:

- Student record management
- Student ID and name management
- Attendance management
- Subject-wise marks management
- Student performance calculation
- Performance result display
- CSV-based data storage
- Organized and modular project structure
- Simple and user-friendly workflow
